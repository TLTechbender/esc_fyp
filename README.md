# Bidirectional BLDC Electronic Speed Controller for UAV Applications

## 1. Project Overview

This project focuses on the design, development and evaluation of a bidirectional Electronic Speed Controller (ESC) for Brushless DC (BLDC) motors used in Unmanned Aerial Vehicles (UAVs).

The proposed system is designed around an off-the-shelf A2212/13T 1000KV BLDC motor. A PWM-based flight controller serves as the intended command source, while an STM32 microcontroller provides the embedded control platform for motor commutation, speed regulation and direction management.

Conventional BLDC ESCs used in many UAV applications are configured for unidirectional motor operation. Reversing the direction of a three-phase BLDC motor through physical reconnection generally requires swapping any two of its three phase connections. Although electrically straightforward, this approach is impractical when directional changes are required after the UAV has been assembled or deployed.

For a multirotor UAV, physically reversing all four motors would require the aircraft to be taken out of operation and each motor's phase connections to be changed manually. This is particularly inconvenient when the operator is not physically present with the aircraft or when repeated directional changes are required. The process also introduces the possibility of damaging connectors, wiring or other components. In integrated ESC designs, where motor connections are soldered directly to a common PCB, the need to desolder and resolder these connections makes physical reversal even less practical.

This project addresses the problem by investigating an ESC architecture that supports electronic control of motor direction through software commands. The intended system will allow the flight controller to request forward or reverse operation and regulate motor speed without requiring physical changes to the motor phase connections.

## 2. Project Aim

To design, develop and evaluate a bidirectional BLDC electronic speed controller that enables software-based control of motor direction and speed for UAV applications.

## 3. Project Objectives

The project is guided by the following objectives:

1. To study the architecture and operation of conventional BLDC electronic speed controllers, with emphasis on their power stages, gate drivers, switching devices and rotor-position detection methods.
2. To design a bidirectional ESC architecture incorporating motor commutation, PWM speed control and direction-transition management.
3. To develop and integrate the hardware and firmware required for bidirectional motor operation, and evaluate the prototype under forward, reverse and transition conditions.
4. To implement a standalone PCB design based on the findings obtained during prototype development and testing.

## 4. System Description

The proposed ESC consists of a power stage and an embedded control system responsible for managing the operation of a three-phase BLDC motor.

The STM32 microcontroller receives an operating command from the external controller and generates the switching signals required by the three-phase inverter. The inverter controls the current supplied to the motor windings through an appropriate commutation sequence.

The intended control functions include:

- Forward and reverse motor operation.
- PWM-based speed regulation.
- Controlled motor startup.
- Direction-transition management.
- Rotor-position detection for sensorless commutation.
- Safe stopping and disabling of the power stage.

The development process will initially use a PC-based interface to generate and test control commands. This provides a convenient means of verifying communication and control functions before integrating the intended flight-controller interface.

The flight controller's PWM command signal and the high-frequency PWM switching signals generated by the STM32 serve different purposes. The former communicates the requested motor operating condition, while the latter controls the inverter's power switches.

## 6. Scope and Limitations

### 6.1 Project Scope

The project covers the design, implementation and evaluation of the following subsystems:

- DC power input and voltage regulation.
- Gate-driver circuitry.
- Three-phase MOSFET inverter.
- STM32-based embedded control.
- External command reception and interpretation.
- PWM generation and speed regulation.
- Six-step trapezoidal motor commutation.
- Sensorless rotor-position detection.
- Bidirectional operation and direction-transition management.
- System-level testing and evaluation.

Development will begin with a prototype assembled from individual circuit sections. The prototype will be used to verify subsystem operation and evaluate the control approach before the design is transferred to a standalone PCB.

### 6.2 Control Method

The proposed motor-control strategy uses six-step trapezoidal commutation. Field-oriented control (FOC) and sinusoidal commutation are outside the implementation scope of this project.

## 7. Development Methodology

The project follows a subsystem-oriented development approach. Each major hardware and firmware section will be designed, documented and tested before integration into the complete ESC.

The development stages are:

1. **System architecture:** Define subsystem responsibilities, electrical interfaces and control requirements.
2. **Hardware design:** Develop the power supply, gate-driver and three-phase inverter circuits.
3. **Microcontroller development:** Configure and verify the STM32 peripherals required for control.
4. **Communication implementation:** Establish the command interface between the external controller and the STM32.
5. **Gate-driver and inverter verification:** Test switching signals and power-stage operation under controlled conditions.
6. **Motor-control implementation:** Develop the commutation, PWM and direction-management functions.
7. **Sensorless control:** Implement and evaluate rotor-position detection using back EMF.
8. **System integration:** Combine the hardware and firmware and evaluate forward operation, reverse operation and direction transitions.
9. **PCB development:** Produce the standalone PCB design using the results and modifications obtained during prototype testing.

## 8. Repository Structure

The repository is organised to separate the complete system design from its individual subsystems, firmware and testing documentation.

Each subsystem has its own documentation and supporting design files. Where applicable, its directory also contains circuit schematics, firmware modules, calculations and test records.

## 9. Subsystem Documentation

Each directory under `systems/` will contain a README describing the subsystem using a consistent structure:

- Purpose and functionality.
- Design requirements.
- Selected components and specifications.
- Operating principle.
- Circuit schematic and explanation.
- Electrical interfaces and pin assignments.
- Design calculations, where applicable.
- Associated firmware, where applicable.
- Testing procedures and results.
- Known limitations.
- Relevant datasheets and references.

This structure is intended to make each subsystem understandable independently while preserving its relationship with the complete ESC.

## 10. Testing and Verification

Testing will be conducted at both subsystem and system levels.

Subsystem testing will verify individual circuit functions, electrical interfaces and firmware behaviour before integration. System testing will evaluate the combined ESC under the operating conditions defined for the project.

Test records will include the test objective, equipment, setup, procedure, expected behaviour, measured results and observations.

The evaluation will consider:

- Correct reception and interpretation of control commands.
- PWM generation and speed-control behaviour.
- Gate-driver and inverter switching operation.
- Forward and reverse motor operation.
- Startup and direction-transition behaviour.
- Sensorless rotor-position detection.
- Response to selected fault conditions.

Results will be documented to distinguish verified functionality from features that remain under development.
